# Kavel

[Kavel](https://www.kavel.ai) is a free AI image and video studio. You can [make videos](https://www.kavel.ai/video), [generate and edit images](https://www.kavel.ai/image), [change a hairstyle](https://www.kavel.ai/image/ai-hairstyle-changer) or [turn a photo into a figurine](https://www.kavel.ai/image/ai-figurine-generator) in the browser.

The SDKs and plugins below call the same studio. Most of them work without an API key on the free tier.
